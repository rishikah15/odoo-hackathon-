# EMPLOYEE-ATTENDANCE

## Employee Profile + Attendance System

This module is developed for the Dayflow Human Resource Management System.

## Features

### Employee Profile

- View personal details
- View job details
- View salary structure
- View employee documents
- View profile picture
- Edit address
- Edit phone number
- Change profile picture
- Edit profile information

### Attendance

- Employee check-in
- Employee check-out
- View own attendance
- Daily attendance
- Weekly attendance
- Monthly attendance
- Present status
- Absent status
- Half-day status
- Leave status

### HR/Admin

- View attendance of all employees
- View employee attendance records
- View Present employees
- View Absent employees
- View employees on Leave

- HTML5

## How to Run

1. Open the EMPLOYEE-ATTENDANCE folder in VS Code.
2. Open `index.html`.
3. Use Live Server if you want to preview the project.
4. The project can also be opened directly in a browser.
